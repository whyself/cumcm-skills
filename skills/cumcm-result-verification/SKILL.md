# 建模计算结果核验

帮助人判断计算结果是否可信，以及结果能够支持多大范围的结论。

从用户关心的结果出发，按疑点选用以下检查，不要求逐项执行。优先检查会改变答案或后续决策的量；材料不足时先做有依据的部分。

## 可选核验清单

- **原题与实现**：沿“题意或模型 → 代码 → 实际输出”追踪关键量，核对单位、索引、时点及跨问传递。把交付解代回原始约束，按原定义重算目标值，留意遗漏约束及取整后的可行性。
- **预测信息边界**：特征在预测当时是否可得？填补、标准化、特征选择和调参用了哪些样本？区分流程泄漏与已测得的指标偏差；全样本描述性分析不直接按预测泄漏判断。
- **独立复算与数值精度**：按疑点选择手算小例、枚举、解析解或独立方法，从原模型或原始数据构造对照，避免共享错误。检查求解状态、残差或步长变化；比较时对齐单位与物理时刻。曲线变平不证明解准确，可行解不等于全局最优。
- **复现与报告一致性**：用实际输入、参数和入口核对关键输出及论文数值，保留旧结果，确认重跑没有误读旧文件。复现成功只说明流程可重复，不能单独证明计算正确；确定性计算不必强求随机种子。
- **结论范围**：分别判断计算是否符合模型、模型是否获数据支持、结论能否推广。说明已检对象、时间与参数范围；小例正确、算法吻合或固定种子下稳定，都不能自动支持更广结论。

## 如何报告

先给最影响可信度的判断，再给位置、实测值与对照值、证据及影响。区分**已通过**（具体检查有证据）、**存在问题**（已定位不一致）、**无法判断**（说明缺口）；未查不能写成通过，风险不能写成已测得的偏差。

说明哪些结果可保留、哪些需重算，以及当前证据支持什么结论。修复后复验受影响的结果。无需固定模板或总分。
