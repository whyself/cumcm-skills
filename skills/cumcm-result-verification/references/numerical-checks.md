# 数值与独立复算

## 按疑点选择检验

可考虑的对照包括：手算小例与程序、解析结果与 Monte Carlo、主算法与另一计算方法、模型预测与实际数据、基础模型与修正模型。选择能针对当前疑点提供证据的组合，不为“独立验证”形式再堆一个模型。

| 问题结构 | 可考虑的检验 |
|---|---|
| 机理、几何、微分方程 | 单位、守恒、边界、极限、可解析特例、步长或网格变化 |
| 参数估计 | 残差、参数意义、多初值、区间、可辨识性与近似条件 |
| 优化、调度 | 原始约束可行性、小实例枚举、解的界、求解耗时、初值与随机性 |
| 仿真、不确定性 | 已知特例、分布依据、随机种子、模拟误差、情景一致性 |

独立复算应尽量从原模型或原始数据另行构造检验量。仅再次调用被审函数，或用同一错误中间表换个算法，不能排除共享错误。说明独立到了哪一层；作者自检不描述为独立人员验收。

## 优化状态与最优性

优化器返回可行解、局部最优和证明最优是不同结论。检查实际状态、停止原因、约束残差、迭代或时间预算，必要时读取最优界与 gap 的定义。`success` 字段本身不足以支持全部判断。

小规模离散决策可用完整枚举；较大问题可用松弛界、已知可行方案、独立求解器或有依据的结构化简对照。启发式多次得到相同目标值可支持经验稳定性，不能据此宣称全局最优。

原变量恢复、后处理与交付精度可能改变可行性，按[约束回代](model-implementation.md)核对实际方案。不同算法目标值相近时，还要确认它们用了相同目标、约束、输入和单位。

## 收敛与数值稳定性

先定位症状：NaN/inf、溢出、病态性、变量尺度、初值依赖、振荡、停滞或预算耗尽。保留实际警告与停止条件。不要用填零、截断或忽略警告掩盖原因。

根据模型检查残差、可行性或有定义的误差；相邻迭代变化很小可能是停滞，损失曲线变平也可能在错误模型或错误尺度上发生。

有证据怀疑数值精度时，再选合适对照：

- 微分方程、积分或离散仿真：在同一物理时刻比较步长或网格细化后的关键输出，核对边界与初值。已有解析特例时优先对照。
- 线性方程与参数估计：结合残差、条件数和输入精度判断；小残差不保证病态问题的解准确。正规方程、求逆或近共线可能放大误差，可用适当的稳定求解作对照，不要求所有问题改成伪逆。
- 相近数相减、指数或概率累积：必要时用等价稳定表达式、较高精度或数量级分析复核。不把数值下溢的零直接当作理论概率为零。
- 多初值或随机求解：记录各次设置与关键输出变化，不仅展示最好的一次。

误差比较先确保量可比，按任务采用绝对误差、相对误差或组合容差。参考值接近零时相对误差可能失真；非有限数值不能因为比较表达式返回假而被判为通过。

## 仿真与不确定性

模拟应符合假定分布、参数、依赖关系和情景。已知特例可用概率递推、精确计算或解析结果对照；Monte Carlo 结果按模拟误差比较，不要求随机估计逐位相同。

固定种子用于复现一次运行，改变种子或增加模拟规模用于观察随机误差。随机误差减小不能排除系统偏差；增加模拟次数也不会增加真实独立观测数。

报告检查的实际规模和适用范围：小例正确支持对应逻辑，经细化稳定支持所检精度，模拟吻合支持所设情景；这些证据不能自动外推到全部规模、参数和现实环境。
