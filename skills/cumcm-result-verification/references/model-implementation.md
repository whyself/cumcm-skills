# 模型与实现对照

## 追踪关键结果

从待核验的答案反向定位：结果表或正文中的量，对应哪个输出字段、哪段计算、哪条模型关系、哪些输入。多问相连时，核对前问实际输出是否进入后问，单位、时点、聚合层级及参数含义是否悄悄改变。

对照时优先看这些已有建模要素，而非模型名称：

- 研究对象、状态量、观测量、未知参数、决策变量的定义。
- 目标函数、约束、状态方程或联立条件及适用范围。
- 参数是题面给定、文献引用、数据估计还是探索情景。
- 近似的成立条件、变量取值范围和边界条件。

可以临时列“模型关系 / 代码位置 / 输出字段 / 核查结论”对照表；简单任务直接说明即可。公式仅有名称或代码缺少注释时，按实际计算解释，不猜测作者意图。无法消除的歧义列为无法判断。

## 题意、单位和数据映射

变量、参数、单位、目标函数和约束应定义完整。检查单位一致、公式符合题面或机理、近似条件明确、数量级合理。特别留意：

- 时间、长度、质量的换算是否在数值上执行；百分数与比例、总量与均值、单次与累计量是否混用。
- 索引对应的对象、时点和方向；表连接、排序或删行后样本与标签是否仍对应。
- 字段实际行列、表头、缺失、分组样本量、分布、异常值和单位；删行、聚合或抽样的数量与理由。
- 重复记录是重复交易、重复测量还是数据重复；异常是否有业务或物理原因。

可用守恒、对称性、单调性、极限与退化情形检查数量级。每个性质先确认适用条件，不把经验趋势当作所有模型都应满足的定理。

同一物理量用不同单位表达时先换算再比较，等价值不应报成数值矛盾。舍入差异按显示精度判断；精度不一致与计算错误分开报告。

## 约束回代

优化、调度和决策结果先代回原始约束。检查等式、不等式、非负性、整数性、容量、时间窗及题设特殊条件中与任务相关的部分。

按原始定义重新计算目标值和约束左端，尤其注意：

- 最小化与最大化的方向，收益与成本符号，求和范围和权重。
- 程序是否遗漏了数学模型中的某条约束，或只检查了变换后的部分变量。
- 惩罚项、松弛变量或连续松弛的解是否被当作原问题的可行解。
- 取整、截断、归一化或导出舍入后，实际交付方案是否仍可行。

约束违背量应有单位和尺度。对 `g(x) <= 0` 可报告 `max(0, g(x))`，对等式可报告绝对残差；若做尺度化，同时保留原单位下的偏差。不直接将不同单位的残差相加当作可信度总分。

容差结合题目精度、数据误差、数值算法及决策用途确定，写出依据。不能为接受已有答案事后放宽约束；连续数值容差也不自动允许违反整数或逻辑条件。

## 定位之后

明确是说明写错、代码实现错、输入口径错，还是当前材料不足以区分。建议尽可能指向局部修正；只有模型本身矛盾、近似失效或现实条件改变时，才讨论模型修订。

原模型算对不等于假设已被现实验证。原题缺失但公式与代码可对照时，可以给局部一致性结论，并保留题意覆盖与现实适用性的判断。
