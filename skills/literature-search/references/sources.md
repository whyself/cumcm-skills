# 来源与检索提示

先考虑学科、语言和实际工具覆盖，再考虑访问方式。公共 API 优先便于重复运行，不表示只应检索公共 API 收录的文献。

## 内置脚本来源

| 来源名 | 适用方向与用途 | 语法/限制 |
|---|---|---|
| `openalex` | 跨学科候选发现，作者、摘要、出版位置 | `search` 关键词；摘要可能缺失，重建倒排摘要不等于已读全文 |
| `crossref` | 期刊和会议书目，DOI 关联 | 使用 `query.bibliographic`，是书目关键词检索，不保证支持 PubMed 式布尔语法；摘要经常缺失 |
| `arxiv` | 数学、物理、计算机预印本 | 简单词组自动转为 `all:词 AND all:词`；复杂 OR、字段、分类检索请提供原生 `all:`/`ti:`/`abs:`/`cat:` 语句；返回预印本时间 |
| `semantic` | 计算机及跨学科发现、摘要补充 | 关键词查询；无 Key 也可尝试，但匿名额度和可用性不保证 |
| `pubmed` | 医学、生物、健康与公共卫生 | 使用原生 PubMed 字段/布尔语法，可混合 MeSH 与 Title/Abstract；需统一邮箱 |

OpenAlex、Crossref、Semantic Scholar 可能共享上游数据。多源的目的首先是增加召回与补元数据，不能按来源数量推断论文可靠性。不要因为用户用中文提问就只查英文，也不要以英文库覆盖不完整为由断言中文文献未被任何英文平台收录。

## 网页补充来源

这些是选源提示，不是已实现接口。先探测环境里真正可调用的网页工具或连接器。每次只选与本题相关的来源。

| 方向 | 网站 | 使用理由 |
|---|---|---|
| 中文期刊/学位论文 | https://www.cnki.net/ 、https://www.wanfangdata.com.cn/ 、https://www.cqvip.com/ | 中文方法表述、本土场景、学位论文；部分检索或全文需机构权限 |
| 广泛发现 | https://scholar.google.com/ 、https://xueshu.baidu.com/ | 补检索遗漏、版本、引用线索；网页片段不能代替摘要 |
| 工程/计算机 | https://ieeexplore.ieee.org/ 、https://dl.acm.org/ 、https://dblp.org/ | 期刊与会议；DBLP 主要是书目信息，无摘要属正常 |
| 数学/运筹 | https://zbmath.org/ 、https://epubs.siam.org/ 、https://pubsonline.informs.org/ | 数学方法、优化与调度，不局限于某个模型库的已有名称 |
| 经济/管理 | https://repec.org/ 、https://www.ssrn.com/ | 计量、管理、经济工作论文，注明发表状态 |
| 机构综合索引 | https://www.webofscience.com/ 、https://www.scopus.com/ | 机构可用时补充检索及引文追踪 |
| 开放全文 | https://pmc.ncbi.nlm.nih.gov/ 、https://unpaywall.org/ 、机构仓储及作者个人页 | 定位实际全文；Unpaywall 通过 DOI 查询，不是通用主题搜索 |

网页访问失败时，用已得到的 DOI、精确题名、作者和年份换源。确需用户访问的来源按环境文档提示设置，并在交付中记录未覆盖部分。不要静默将无法访问当作没有相关文献。

## 扩词和继续检索

- 将主题拆成对象、问题、方法、约束、场景；同义词、缩写全称和专业译名分别考虑。
- 精确检索无结果时逐步移除非核心限定词；不要悄悄改变用户明确限定的年代或研究对象。
- 方法名已知时同时检索原始提出论文、后续综述和相近应用；经典方法不机械加“近五年”限制。
- 结果偏题时检查缩写歧义、上下位概念、应用条件，而非只增加获取数量。
- 获得种子论文后，可从其参考文献、被引和作者后续工作扩展；本包未实现引文图接口，使用实际可用工具完成。
- 搜索存在反例、局限或相反结论的研究可以减少单向筛选，但相关性判断以用户问题为准。
