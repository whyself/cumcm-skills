# 文献检索

获得相关、可追溯的候选文献。模型理解需求、扩词和判断相关性，脚本负责请求、解析、去重和保留记录。

## 检索与交付

沿用用户的主题、年份、语言和文献类型限制，按对象、任务、方法及场景扩展中英文检索词。根据学科选择互补来源；内置 OpenAlex、Crossref、arXiv、Semantic Scholar、PubMed，其他来源通过实际可用的网页工具补充。

需要运行检索或解析 DOI 时，读[命令与候选处理](references/usage.md)对应部分；需要比较来源与检索语法时，读[来源说明](references/sources.md)。数量上限是本轮获取范围，不代表数据库全部命中。覆盖不足时扩词或换源，按用户要求及新增相关结果决定何时收束。

根据标题和可用摘要判断相关性，保留证据不足但可能相关的候选。缺 DOI 或全文链接不自动淘汰；书目匹配、来源数量和引用量不能证明论文结论可信。原文摘要、译文与模型概述分开，缺失字段如实说明。

交付适合当前问题的候选与推荐理由，保留可追溯书目和来源；完整记录可放文件。已有结果按需筛选，无需重新检索。部分来源失败时继续使用可用结果并说明覆盖缺口，失败不等于零命中，零命中不能证明研究空白。默认做到候选检索与筛选；请求已包含后续工作时按其范围继续。

## 运行环境

脚本仅需 Python 3.10+ 标准库，路径相对本技能目录，输出写入用户项目。首次使用且环境未知、环境变动或运行失败时，用 `python scripts/literature_search.py doctor` 检查；它不证明联网可用。

需要配置 Python、Key、邮箱、代理或诊断连接时，读[环境配置](references/environment.md)。使用已有配置；缺可选 Key 时可先用其他可用来源。实际 Key 和邮箱留在用户私有配置或环境变量中，不写入技能、计划、结果或对话。只有需要用户申请账号、输入凭据或登录时才交由用户操作。

修改检索脚本时参考[脚本维护](references/maintenance.md)。
