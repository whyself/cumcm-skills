# 总语言规则

适用于所有功能块。规则为对展示论文表达方式的归纳和保义编辑约束，不是竞赛强制规范。以下规则不授权技术修订。

## G1 用具体动作承载信息

把“对模型进行一个求解的过程”改为“求解模型”；把“对每个方案的总成本进行了计算”改为“计算了每个方案的总成本”。动词对应已存在的宾语，不补原稿没有的模型、数据和输出。保留完成状态。

依据：[S23A](sources.md#s23a) 的坐标变换目的句、[S24A](sources.md#s24a) 的模型与求解动作、[S25B](sources.md#s25b) 的数据处理句。

## G2 连接词必须忠实于逻辑

“首先、随后”表达顺序，“由于、因此”表达因果，“在……条件下”限定范围，“即”声称对应或等价，“但”保留转折。可修顺序和机械断句，不用连接词创造原稿未说明的因果、等价、递进或方法依赖。不能把“或者”改为“并且”。

依据：[S23A](sources.md#s23a) 的可选坐标转换方向、[S24B](sources.md#s24b) 的前后问题变化。

## G3 少修饰不等于删主张

可删除不承载意义的“进行一个”“可以说是”等空转部分。不能把“约、至少、仅、尚未、较为、可能、预计”等当作赘词删除。笼统的价值评价若本身是作者主张，也不能以去套话为由直接删掉；先保留，必要时在正文外提示其依据或范围。

“显著”在统计结论中涉及检验，在普通描述中也可能是程度词；不自动互换，不制定禁词表。既不把“相关”改成“影响”，也不把原有因果断言静默改成相关断言。

依据：[S23C](sources.md#s23c) 的例外与“仍然可能”、[S24B](sources.md#s24b) 的“较为稳定”、[S25C](sources.md#s25c) 的“有待验证”。

## G4 术语统一以含义明确为前提

给定上下文明确为同一对象的口语代称，可以统一成原稿已定义的名称。若“数量／面积”“损耗／损耗率”“利润／平均利润”涉及可能不同的概念，保持原用词并标疑，不凭相邻公式、常识或优秀论文纠正。不能把“我们采用”改成“本文提出”。

依据：[S24C](sources.md#s24c) 的数量与面积差异、[S23C](sources.md#s23c) 的损耗口径。

全称与缩写冲突、指标名称疑似错置时，同样保留原表述并外置核查。不要凭常识把它们改成“应有的术语”。补充依据：[S22C](sources.md#s22c) p005 的 alr/clr 并存、[S21B](sources.md#s21b) p021 的指标名称疑点。

## G5 以双向语义核对防止漂移

润色前后逐项核对：

| 信息 | 易造成变意的改写 |
|---|---|
| 主体、样本单位 | 检测次数变成受试者人数；群体均值变成个体预测 |
| 比较与量词 | “不小于”变“高于”；“多数”变“全部”；百分点变百分比 |
| 条件与否定 | “并非所有”变“所有均不”；删除“在假设成立时” |
| 知识状态 | 假设变事实；预测变观测；未发现差异变成相等 |
| 工作状态 | 拟采用变已采用；尚未验证变已经验证 |
| 断言强度 | 可能变必然；保证变有助于；最优变较优 |
| 效果判断与目标 | “可能提高”只剩“旨在提高／以期提高”，丢失可能性判断 |
| 归属 | 作者观点变公认结论；引文支撑范围随拆句扩大 |

数字和数学符号一致只是必要条件，不足以证明语义一致。优先核对句子实际声称了什么，而不是关键词是否还出现。

## G6 让句子自然，不制造统一腔调

清楚的短句可以保留；长句只在语义边界处拆开，条件与例外仍覆盖相应主张。沿用原稿的“本文／我们／本研究”习惯，不为了正式一律改成无主句。不强制每段三句话、每问同样长度或每句使用“针对……基于……”。

样本展示了不同章节和句法组织，见[语料范围](sources.md)。这些是可用表达，不是填写模板。

## G7 语言疑点与科学疑点分开处理

唯一可确定的语病可直接修；术语冲突、结果矛盾、公式疑点、过强结论、来源缺失及比较对象不明，保留相关原句或只做不触及疑点的修改，另列“位置＋疑点＋待确认信息”。不要运行新实验来为润色补依据，也不把编辑者建议包装成作者成果。

依据：[S23B](sources.md#s23b) 的不完整比较句、[S24C](sources.md#s24c) 的变量定义差异及 [S25B](sources.md#s25b) 的保证性评价反例。

## G8 段落围绕同一中心组织已有信息

原稿已有同一对象的事实、推理与解释时，优先让相关句子相邻，突出该段在说明什么。可在用户指定范围内局部拆分混杂长段，但不强制每段“先事实、后含义”：先概括再列依据、先目的再方法，也可以清楚。调整后要保留条件和引用的作用范围，不因分段丢失例外，不另造中心句或结论。

范文依据：[S24B](sources.md#s24b) p022 的“比较基准—分情形差异—总体稳定性”；[S25C](sources.md#s25c) p007 按固定效应、随机效应分别说明作用。外部经验及采用边界见[仓库经验核验](upstream-validation.md)。
