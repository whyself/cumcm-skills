# 问题分析

适用于独立“问题分析”章、每问前的思路段和总体路线说明。不要求另设同名章节。

## P1 整理已有的方法理由

原稿已经说明难点和方法依据时，用“问题特征—处理思路—分析对象”连接。具体对象优于泛泛的算法介绍。若只有“采用遗传算法”，只能把这句话写顺，不能补上“由于目标函数非凸、不可导”等未给依据。

依据：[S24B](sources.md#s24b) p003；[S25B](sources.md#s25b) p002。

## P2 保持步骤的实际关系

顺序、并行、分阶段、迭代和可选路线分别表达。“先确定……再求……”不能改成同时优化，“分别计算”不能改成联合估计。减少重复的“然后”时仍保留依赖关系，不靠“因此”制造推导。

依据：[S23A](sources.md#s23a) p002；[S24A](sources.md#s24a) p003。

## P3 后续问题突出已有的继承与变化

当前文已说清前问的模型、参数或结果被复用，可以用明确指代减少重复；同时保留本问改变的条件或规模。不能推断下一问必然包含前问可行域、必然优于前问，或已经验证原模型仍适用。

依据：[S23B](sources.md#s23b) p002；[S24B](sources.md#s24b) p003。

区分复用模型、沿用参数、传递前问输出及用另一结果作检验；这些不是同一种承接。只有原稿说清关系时才用“在前述模型基础上”等连接，不能为统一主线把另建模型改成扩展模型，或把使用前问结果写成验证前问。补充依据：[S25B](sources.md#s25b) p001和[S24B](sources.md#s24b) p003。

## P4 思路与成果保持原时态

“拟通过”“需要考虑”“可尝试”与“已完成”“结果表明”不同。不要因为分析章常放在求解前就把原稿所有已完成动作改为计划，也不因论文已成稿把计划改成成果。

自拟保义例：

原稿：“第三问接着用第二问的成本计算方法，不过还要考虑半成品，所以要多加一些决策变量。”

润色：“问题三沿用问题二的成本计算方法，但还需考虑半成品，因此需要增加相应的决策变量。”

只整理原有理由；不能增加变量个数、算法或复杂度结论。
