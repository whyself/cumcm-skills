# 数据与成图检查

## 数据对应与统计说明

- 对照源文件、实际读取的工作表、字段映射和绘图数组。检查 ID 配对、类别顺序、单位、分组计数、重复值、缺失处理和变换前后数量；抽查关键点与汇总值。
- 样本量 n 应对应独立的测量或实验单元；重复读数、交叉验证折次、随机种子和独立样本不能混称。
- 区分均值与中位数、SD 与 SEM、置信区间与预测区间。误差棒、阴影、箱体、须和离群点的定义写入图注；没有重复观测或相应结果时不能编造误差。
- 显著性、相关系数、AUC 和其他图中指标来自实际计算或可核对的结果；检查检验对象、配对状态及多重比较处理。不要用星号替代效应大小，也不能用误差棒重叠与否直接判断显著性。
- 热图说明标准化、缩放及聚类；回归说明是描述性拟合还是推断。模型比较保持数据划分、基线和指标定义一致。

程序能运行、图片能打开、旧结果可复现分别说明不同事情，不能单独证明模型正确。缺材料或未执行的检查标明无法判断。

## 实际读图

先运行 `audit_layout(fig)` 抓缺字、画布越界和刻度重叠；再打开最终 PNG，在最终使用尺寸下检查整体与每个面板：

1. 中文、负号、希腊字母及上下标有没有乱码或方框。
2. 坐标轴、刻度、图例、标注有没有被裁切；数据点、误差棒是否被轴范围截断。
3. 图例或文字有没有压住数据，显著性标注是否互相遮挡。
4. 子图、标签、色条、共享轴是否对齐，间距是否足够，比较面板的尺度是否一致。
5. 类别颜色是否可分，同一变量跨图是否同色同符号；灰度下能否通过线型或标记区分。
6. 主次是否清楚，文字在最终尺寸下能否阅读，是否需要减少标注、分面或拆图。

机器给出的空白风险与布局 WARN 需要读图判定，不能自动等同于错误。修复后重新导出并检查最终文件；只传图像路径给文本模型不算完成读图。

## 文件与交付

`python "<包目录>/scripts/inspect_image.py" figure.png` 检查文件能否解码、尺寸、DPI、透明度和空白风险，不能代替数值核对或视觉判断。

折线、条形、散点等优先保留 PDF/SVG 矢量版本及可编辑文字；PNG 通常至少 300 DPI。固定物理尺寸导出时使用 `tight=False`，以免紧边界裁切改变宽高。图片用于正文时，字号按实际插入宽度检查，不能仅看放大的屏幕预览。

交付代码、图片与运行方式；统计汇总保留其源数据或结果表。说明影响解释的数据处理和未解决事项，不写没有证据的“全部通过”。
