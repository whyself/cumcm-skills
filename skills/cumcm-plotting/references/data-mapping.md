# 绘图资产适配

在模板字段、数据结构或统计逻辑需要调整时查阅。示例和预览可提供结构或样式，但不能证明它们适合当前数据。

## 决定复用范围

根据图意与数据结构选择保留哪些代码：含义和结构一致时可以直接替换输入；字段不同则调整映射；统计逻辑不同但样式合适时仅复用样式；不适配时重新绘制。无需先给候选分级或填写复用表。

必要时查看预览并结合代码确认图中实际使用的分组、统计量、变换与不确定性。例如二维联合密度不能直接当作一维边际密度的实现。

## 数据对应

确认实际使用字段的含义、单位、分组顺序与配对关系。明确映射可直接在代码中表达；涉及多表关联、单位换算、聚合或容易混淆的字段时，再用简短说明记录对应关系及处理依据，无需每次另写映射文档。

沿用指定字段和顺序；材料已给出唯一合理对应时直接处理。只有无法从上下文判断且会改变图意或统计结论的歧义才向用户澄清。保持 ID 与测量值对应，不以方便为由换列或改变样本单位。

## 变换与统计条件

仅检查实际使用的变换：

- 对数变换通常要求正值；符号对数或伪计数需有合理依据并说明。
- 比率与归一化检查分母及零值处理；平方根检查非负条件，Min-max 检查常量列。
- 分箱与密度估计检查观测支持及带宽；相关、PCA、聚类和统计标注检查缺失值处理与样本单位。

条件不满足时调整方法并说明影响，不能为保留模板而扭曲数据。

## 数据与交付

默认保留请求的观测与变量，不为美观悄悄删点或改变统计量。需要筛选、聚合或采样时保留理由、处理规则和必要的样本数量；随机采样记录可复现参数。真实结果中不能残留模拟值，演示应明确标识。

复制模板到用户工作目录后适配。记录影响复现或解释的输入、变换和统计口径，可写在代码、结果说明或已有记录中，无需单独创建 QA 笔记。

运行适配后的代码，对照真实输入核对受影响的数值、分组与标注，并检查最终图片。程序成功不能单独证明图意正确；修改标签或样式时重点检查相关显示，改变计算或映射时复核对应数据。
