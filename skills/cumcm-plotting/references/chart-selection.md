# 选图参考

## 决策依据

同时看变量数量与类型、表达意图、样本规模。同一批数据，整体差异、动态变化与个体差异需要的图可能不同。模板外观与这些条件冲突时，改变图型或只继承样式。

| 数据与目的 | 常用图型 | 需要注意 |
|---|---|---|
| 单个连续变量的分布 | 直方图、箱线图、KDE | 分箱与带宽影响形态；小样本优先展示实际点，避免平滑制造结构 |
| 类别之间的数值比较 | 条形图、点图 | 保留有含义的分类顺序；排名任务可按值排序；柱长表达大小时通常从零开始 |
| 分组观测的差异 | 箱线/小提琴叠原始点、区间图 | 不只画均值掩盖分布；组数多时分面；每组样本量及独立单元需明确 |
| 同一对象的两条件变化 | 配对点线图、配对云雨图 | 按 ID 配对，不能按行号连线；不要将配对数据当独立两组 |
| 两个连续变量的关系 | 散点、回归与区间 | 无顺序的数据不随意连线；过绘制可用透明度、hexbin 或声明规则的聚合 |
| 时间或有序变量的趋势 | 折线、阶梯图、置信带 | 按真实顺序排列，显示缺测与间隔；区分观测、预测和插值 |
| 多变量相关 | 相关热图、散点矩阵 | 说明相关方法、缺失处理、缩放及聚类；相关不能直接解释为因果 |
| 构成与层次 | 堆叠条形、百分比堆叠、树图 | 区分总量与比例，比例分母一致；类别少且确需表达份额时可用饼图 |
| 二维参数与输出 | 热图、等高线、响应面 | 只有连续坐标且曲面有意义时使用三维；说明插值与色标范围 |
| 分类性能 | ROC、PR、混淆矩阵 | 保留真实标签与预测概率的对应；类别不平衡时关注 PR；区间来自真实重复或重采样 |
| 回归性能 | 预测-实测散点、残差图 | 叠加 y=x 参考线；拟合线不能代替理想预测线；比较面板保持量纲一致 |
| 多指标评价 | 点阵、平行坐标、雷达图 | 明确指标方向、单位和缩放；雷达面积受轴顺序影响，不能用面积证明整体优越 |
| 流量、路径与网络 | 桑基、网络、路径图 | 节点、边、权重与方向须有现实含义，避免装饰性连线 |

样本量与类别数是可读性和统计稳定性的提示，不是通用的硬阈值。维度过多时先考虑拆图或分面，不为凑图型多样性重复展示同一证据。不同量纲优先分面；双轴确有必要时交代两轴范围，检查刻度是否制造关联。

## 数模场景

每张重要图都回答“读者看完应该发现什么”，根据需要选择：

- 数据诊断：异常、缺失、相关、时间趋势、频谱与空间格局。
- 核心规律：参数与输出、阈值、策略切换、敏感性。
- 最优方案：路径、网络、排程、决策矩阵、空间分布。
- 验证：理论与仿真、预测与实测、残差、收敛与误差区间。
- 不确定性：置信带、风险前沿、敏感性热图；两个参数共同决定策略时可用决策区域图。

图中的文字、符号、单位与模型说明一致。仅要求改样式时保持既有数据与统计含义；发现实质问题应说明影响。
