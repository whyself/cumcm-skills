# 绘图

帮助人选择能表达数据与问题的图，交付实际运行的代码和检查过的图片。模板提供可选版式，图型、统计口径和取舍由当前数据与需求决定。

## 开始时

沿用已有的数据、绘图语言、输出用途和风格要求；未指定语言时优先 Python，已有 MATLAB 或 R 项目则沿用。实际运行前检查环境，缺少解释器、所需库或中文字体时先安装并验证，再绘图。安装失败时说明实际错误，继续能完成的部分，不把未执行的代码当作已成图。具体命令见[环境准备](references/environment.md)。

所有路径相对本目录。资料和模板留在包内，代码副本、图片和运行记录写入用户工作目录。修改已有图时从相关步骤开始，不重复无关工作。

## 选图与模板

1. 弄清要比较、解释或探索什么；检查字段含义、单位、类型、缺失、分组样本量、时间顺序和配对关系。`scripts/profile_data.py` 可提供初步数据剖析，类型与图型提示仍需结合实际含义核对。
2. 已指定图型、模板或修改位置时直接沿用。需要选择模板时，在[模板目录](references/template-catalog.md)按图型或关键词查相关条目，再读候选代码与必要预览，无需通读目录。不确定图型时可参考[选图建议](references/chart-selection.md)，也可从零绘图。
3. 普通绘图请求按数据与目的选合适方案并继续，需要时简述理由；存在实质取舍才提供备选。用户明确要求自己选时展示候选及可用预览，等其选择。
4. 落实字段映射、统计口径、轴与颜色含义、面板作用及输出尺寸；歧义会改变图意时先澄清。探索性任务先明确问题，结论随数据形成。

## 生成与运行

涉及字段、统计逻辑或数据结构适配时，按需查[数据映射与适配](references/data-mapping.md)。复制候选后修改；检查并替换演示数据、硬编码统计量和旧输入输出路径。保持样本 ID、类别与数值对应，记录筛选、排序、聚合、插值和归一化的依据，不为美观悄悄删点或改变统计量。

按所选代码检查并安装额外依赖，实际运行，检查报错、告警和输出文件。普通模板含示例计算，不代表已有真实模型结果；缺少预测、SHAP、检验等结果时先判断是否有材料与授权计算，不能沿用示例值。

- Python 样式：`scripts/setup_style.py` 的 `setup_style(journal='general', lang='zh')`；英文图用 `lang='en'`。字号按最终使用尺寸决定，配色承担一致含义，并用线型或标记辅助区分。
- 基础代码与数模用法：按图型阅读[绘图配方](references/plot-recipes.md)相应章节；其中模拟数据仅用于示例。
- 多面板：每个面板回答不同的问题，按信息关系安排布局，必要时用 `scripts/layout_tools.py`。
- 导出：`scripts/export_figure.py` 的 `export_figure()` 支持 PDF/SVG/PNG 与灰度预览；固定物理尺寸时使用 `tight=False`。通常导出矢量图和至少 300 DPI 的 PNG，具体服从用户用途。

## 检查与交付

核对本次改动涉及的数据、统计说明和成图，并打开最终图片检查遮挡、配色与可读性。需要详细检查项时参考[质量检查](references/quality.md)；`scripts/visual_qa.py` 的 `audit_layout(fig)` 可辅助发现缺字、越界与刻度重叠，`scripts/inspect_image.py` 可检查图片可读性与空白风险。按疑点选用辅助工具，无需每次串行运行全部检查。

有问题就修改对应代码、重新运行并读图；同一问题反复出现时定位原因，不能只循环换样式。程序成功退出不等于数据或图意正确；无法检查的部分明确说明。

交付图片、可运行代码、运行命令及必要依赖，简述选图理由、数据处理与检查中影响使用的事项。有统计汇总时保留其数据来源或导出的汇总表，便于核对；不用固定数量的图或报告凑齐流程。
