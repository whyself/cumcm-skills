# 图表规划参考

仅在规划涉及相应内容时读取；按实际材料选用，不要求逐项满足。

## 图表规划：先说明用途

从“读者需要看清什么”选择图表，优先盘点已有材料。每项建议交代所属章节、表达目的、数据或公式来源、需要展示的变量与比较关系，以及正文应如何解释。图表编号未定时可用描述性暂名，不虚构已存在的图片、统计值或路径。

| 表达需要 | 可选图表与要点 |
| --- | --- |
| 理解变量关系或模型衔接 | 机理示意图或路线图，展示对象、关键关系与真实输入输出；不要只有“输入→建模→运行→输出”。 |
| 说明算法中的关键决策 | 伪代码或流程图，突出约束判断、更新和终止等实际步骤；简单算法可用文字。 |
| 比较方案、给出精确答案 | 结果表或比较图，明确指标、单位、比较口径与适用情景；完整方案较长时正文摘要、附录详表。 |
| 展示趋势、分布、关联或空间结构 | 根据变量类型选折线、分布图、散点图或空间图，明确横纵轴、分组与必要基准。关联图不单独支撑因果解释。 |
| 判断误差、不确定性或适用边界 | 预测与观测对照、残差图、区间图或参数响应图；说明区间或误差的来源、数据需求及计算是否已完成。 |

数据未齐时写清所需字段和生成条件，不先断言图将证明改善。图与表可以互补，但同一结果无需反复展示；面板、颜色和图型应服务比较关系，不为多样性强行换图或凑数量。

正文安排引导、图表证据及解释，图注承担读图所需的对象、单位和条件说明。核心答案、关键检验及改变结论的反例或限制留在正文；延长推导、重复诊断和大批中间结果可移附录。不能为了主线好看隐藏不利结果。
