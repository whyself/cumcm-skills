# 论文内容规划

把已有大纲和材料组织成可讨论、可修改的写作安排，让人看清每节要回答什么、依据在哪里、如何展开、还缺什么。主动推荐并解释取舍，人的方向和当前授权决定推进范围。

以下骨架、写法和检查点都是供选择的参考建议，可以按题目、已有材料和人的意见合并、删减、重排或换用更合适的组织方式，不要求逐项满足。保留必要的事实边界：建议中的内容不能冒充已经完成的工作，结果和文献不能编造。

## 从已有材料出发

沿用用户已有的大纲、模型路线、术语、篇幅要求和讨论结论。先读指定材料，再按需要查看相关题面、建模笔记、公式、结果表、图和文献摘录；无需先补齐统一目录。只规划局部时，查看其必要上下文，不重排整篇。

- 对齐题目要求的输入、约束、输出与大纲落点。检查是否遗漏了题目真正要的答案，而非只看章节是否齐全。
- 辨认材料中的题设、建模选择、推导、实际结果、作者设想和待做工作。计划中的验证、预期改善和未读文献不能充当已有证据。
- 已有工作优先复用；若发现模型与结果不符、版本矛盾或论断过强，指出具体位置及其对写法的影响，推荐修订，不盲目沿用，也不默默替换为自己设想的结果。
- 材料不足时，先给已有信息支持的规划，把缺口挂到受影响的章节或论断上。只有会改变主线、关键结论或用户指定范围的歧义才需要追问；不要求用户逐节审批或确认理解。

这里的默认交付是内容规划。检索、计算、画图、正文写作和排版是否继续，依当前请求与已有授权判断，不自动启动整套生产流程，也不阻断已经授权的后续工作。

## 先理清主线，再细化章节

用简短的话说明论文打算回答的核心问题、现有方法和证据能支持的结论范围。结果尚未形成时，描述待回答的问题，不预写成功结论。

逐问辨认真实联系：前问的哪个参数、状态、预测或方案进入后问，后一问放宽了什么条件，是否需要传递前问的不确定性。共享定义和方法集中说明，后问展开变化与新增内容；独立子问题按各自任务组织，不为了连贯强造递进关系。

已有大纲能承载论证就细化；存在重复、断层或结论无处落脚时，给出调整及理由。章节顺序服务读者理解，材料整理和实际写作顺序可以不同。通常先整理核心模型、结果和检验，最后据正文确定摘要；这不是阶段门槛。

## 可参考的章节骨架

下面是国赛论文模板提供的一种常见骨架，可用于检查内容落点或讨论结构。没有现成大纲时，也应结合本题选用；不需要逐节照搬。已有大纲可直接细化，不必转换成这套编号和层级。

```text
首页：论文标题、摘要、关键词
一、问题重述
二、问题分析（按实际各问设小节）
三、模型假设
四、符号说明
五、模型的建立与求解
    5.1 问题一模型的建立与求解
        模型的建立；模型的求解（包含结果与解释）
    5.2 问题二模型的建立与求解
    ……按实际题目数量展开
六、模型的分析与检验
七、模型的评价、改进与推广
八、参考文献
附录：支撑材料文件列表、源程序及其他补充材料
```

标题和小节名可随内容调整。问题分析通常紧接问题重述，也可在假设、符号之后，或融入各问的模型建立；独立设置时以思路和依据为主，避免提前堆放结果。模型的分析与检验可以独立成节，也可放在对应问题内，注意避免重复。数据处理可在相关模型建立前交代，共享内容较多时可单列；位置由读者理解模型所需的信息决定。

模型评价可围绕有依据的优势和局限展开，改进和推广按材料与任务选用。没有推广内容时，可简化为“模型的评价与改进”或“模型评价”，也可采用更贴切的标题；不为保留栏目补造内容。结论可在各问小结和评价中收束，也可按表达需要单列。

这是内容组织参考，不是当届官方格式规定。模板中的讲解笔记、示例公式占位和教程信息只用于理解写法，不作为论文内容；实际篇幅、编号和提交要求以适用的当届规则及用户要求为准。

## 每节怎样安排

对需要细化的章节，结合实际材料说明以下内容；可写成短条目、段落安排或表格，不必每节填满同一模板。

- **本节任务**：读完后应理解什么、能回答原题哪一项；拟提出的核心论断及其适用条件。
- **展开顺序**：具体说明先交代什么，再解释或比较什么，最后得出什么。按需要细化到段落的主要任务，如动机、数学定义、证据、解释或限制；避免只列“模型建立、结果分析”等空标题，也不按句数拆碎论证。
- **材料落点**：所用笔记、公式、表中字段、图或文献摘录及可定位位置；哪些已具备，哪些需要补充。规划中可保留实际文件路径供核对，写入论文时转换为正常的公式、图表、附录和文献引用。
- **前后衔接**：承接何处的定义或结果，为下一节提供什么；同一内容再次出现时，应承担新的解释或总结作用。
- **详略与缺口**：哪里需要充分解释，哪里可合并、简写或移附录；缺少什么证据会使哪句话暂时不能成立，建议补什么或怎样收窄表述。

### 常见章节的内容参考

以下按写作功能选用，不要求新增全部章节或套用固定题目数量。

| 写作功能 | 应安排的内容与展开重点 |
| --- | --- |
| 标题与关键词 | 标题可围绕研究对象与主要模型或方法，也可直接概括赛题所研究的问题；不要把全部算法塞入标题。关键词选实际使用的主要模型及能体现论文内容的主题词，不按占位符个数凑词。 |
| 摘要 | 可用简短开头概括问题和整体思路，再按实际各问安排“解决什么问题、使用什么方法、得到什么结果”；也可按贯穿全文的主线组织。结尾是否总结、突出亮点或说明适用范围，依材料决定。通常在正文明确后提炼，数字和结论同源；未完成结果列为规划缺口，不填预期值，不机械限定段数和行数。 |
| 问题重述 | 将问题背景与各问任务分开组织，压缩背景，用自己的话说明研究对象、已知条件、核心矛盾和具体要求。不要复制长题面或提前展开求解。 |
| 问题分析 | 按各问说明题目信息、关键难点、数据或变量特征、模型适用理由、求解与评价思路，起到实际问题向数学表达过渡的作用。解释为什么这样做，不提前陈列求解结论；复杂思路可配有真实信息关系的图。 |
| 模型假设 | 从实际使用的因素简化、模型成立条件、参数形式或分布及题目相关约定中整理必要假设，说明依据、影响和使用位置。题面已给条件可注明为已知条件，不冒充自设假设；不能仅因事件概率小就默认忽略其影响。 |
| 符号说明 | 重要变量按“符号、说明、单位”成表，统一含义和索引；临时量可就地定义。符号表不能替代变量在正文首次使用处的解释。 |
| 数据说明与处理 | 来源、字段口径、实际存在的问题、处理理由与关键参数、处理前后影响。共享处理集中写，局部处理放在对应问题；没有做过的清洗不补写成事实。 |
| 逐问模型与求解 | 从本问目标和动机进入变量、关系与关键推导，说明公式能计算什么；必要时集中汇总目标、约束或联立模型，再交代算法理由、参数、求解和输出。写数学与现实含义，不写成函数调用说明书。 |
| 结果与分析 | 展示直接回答本问的结果，用关键数值、方案或规律支撑，解释其含义与条件；再作与本论断相关的比较或检验。小结收束本问并说明真实衔接，不重复数字清单。 |
| 模型的分析与检验 | 区分模型使用前的适用条件检查与求解后的结果检验：前者通常在模型建立附近交代，后者可随结果或集中讨论。按疑点选择误差来源、残差、对照、约束回代、灵敏度或边界检查，说明检验对象及已有结果；不为凑章节强做灵敏度，也不把稳定性等同于灵敏度。可行不等于最优，拟合不等于预测有效，收敛曲线不能单独证明准确。 |
| 评价、结论与推广 | 逐问回应题目；综合已有结果，说明具体优势、局限影响哪个结论、适用于什么范围，改进建议针对真实缺口。与结果不同，这里强调综合含义，不逐图复述。 |
| 参考文献 | 将引用他人或公开资料的成果落到正文使用处，文末条目与正文双向对应；书籍、论文、网络数据或报告分别保留相应书目信息，格式按实际要求统一。 |
| 附录 | 模板提供“支撑材料文件列表、源程序、其他补充材料”的组织参考；具体项目和顺序按实际内容及提交要求选择。程序说明可交代语言、用途及对应问题；长证明、详细求解、外部数据、大流程图及繁杂结果按需补充，正文保留关键答案和引用入口。只列实际存在或明确待补的材料，不把模板示例当成已有文件。 |

篇幅按题目重点、推导难度和证据价值分配，不按各问平均分，也不靠背景或重复检验凑字数。需要页数或字数建议时，基于用户限制给可调整预算；历史经验不能冒充当届官方要求。

## 图表规划：先说明用途

从“读者需要看清什么”选择图表，优先盘点已有材料。每项建议交代所属章节、表达目的、数据或公式来源、需要展示的变量与比较关系，以及正文应如何解释。图表编号未定时可用描述性暂名，不虚构已存在的图片、统计值或路径。

| 表达需要 | 可选图表与要点 |
| --- | --- |
| 理解变量关系或模型衔接 | 机理示意图或路线图，展示对象、关键关系与真实输入输出；不要只有“输入→建模→运行→输出”。 |
| 说明算法中的关键决策 | 伪代码或流程图，突出约束判断、更新和终止等实际步骤；简单算法可用文字。 |
| 比较方案、给出精确答案 | 结果表或比较图，明确指标、单位、比较口径与适用情景；完整方案较长时正文摘要、附录详表。 |
| 展示趋势、分布、关联或空间结构 | 根据变量类型选折线、分布图、散点图或空间图，明确横纵轴、分组与必要基准。关联图不单独支撑因果解释。 |
| 判断误差、不确定性或适用边界 | 预测与观测对照、残差图、区间图或参数响应图；说明区间或误差的来源、数据需求及计算是否已完成。 |

数据未齐时写清所需字段和生成条件，不先断言图将证明改善。图与表可以互补，但同一结果无需反复展示；面板、颜色和图型应服务比较关系，不为多样性强行换图或凑数量。

正文安排引导、图表证据及解释，图注承担读图所需的对象、单位和条件说明。核心答案、关键检验及改变结论的反例或限制留在正文；延长推导、重复诊断和大批中间结果可移附录。不能为了主线好看隐藏不利结果。

## 文献规划：明确支撑哪句话

优先查看已有文献的可用摘录或原文位置，分别判断它能支撑领域背景、模型理论、算法出处、参数依据还是对比解释。文献应贴近对应论断，不把参考文献表当作与正文无关的装饰，也不因为材料中出现某篇就必须引用。

- 已读且有依据的材料，标明拟引用章节、支持内容及实际可定位的页、节、公式或摘录；不编定位。
- 只有题名、搜索结果或书目时，列为候选，说明需要核实的内容。书目真实与论断得到支持是两件事。
- 缺文献时，提出具体检索需求：要支撑的论断、对象和方法、中英文关键词及适合的来源类型。没有找到原文就保持待核实，不凭记忆补齐作者、年份、DOI 或结论。
- 优先相关的原始方法、权威资料及符合本题条件的应用研究；不限定名刊、不固定数量，也不强行给自有推导和实际结果配外部引用。已有推导仍需说明成立条件。

## 讨论和修订

先说明最影响写作的判断，再给所需范围的章节安排，以及有实际影响的材料缺口和取舍。通常可用“章节与任务｜展开顺序｜已有材料｜图表与文献｜缺口或调整”组织讨论；简单局部任务用短条目即可。

提出首选安排及理由，只有存在实质取舍时才提供备选，如检验随各问展开还是集中比较。用户提出修改后，更新受影响的章节、图表、引用和前后依赖，保留仍然有效的内容；不每次重建全篇规划。

交付前回看：题目要的答案是否有落点，各节是否有具体展开内容，关键论断与材料是否相符，图表和文献是否有用途，未完成工作是否清楚，是否存在重复或被藏起的限制。检查服务于当前任务，不设统一数量、评分或验收门槛。
