# 模型库修订说明

本目录的模型库包含七类、64 个一级编号条目的介绍、公式、适用范围和候选文献。它是建模参考资料，不是可直接运行的代码库；具体实现可使用模型自身知识和合适的成熟库。

本次对选型、使用条件和部分公式做了检查，不是对全部条目、算法变体和参考文献的全面认证。下表是已直接改入库文件的内容，查到对应方法时可据此理解修改。

| 类别与位置 | 原资料问题 | 已做修订 |
|---|---|---|
| 01 LP 适用范围 | 直接把 0-1 变量作为普通 LP 特征 | 区分标准指派的整数性与附加约束后的整数规划需求 |
| 01 多目标拥挤度 | 左侧下标与求和下标混用，相邻点和零范围未解释 | 使用总距离 D_i，明确按每个目标排序的相邻点、边界及零范围处理 |
| 02 线性回归 | 逆矩阵公式缺少秩条件，应用表直接写因果分析 | 补满列秩与数值求解说明，关联和因果分开 |
| 02 神经网络 | 给定误差符号下，梯度更新的符号相反 | 改为负梯度，并注明平方误差约定 |
| 02 SVR 对偶 | 只有目标，缺少可行约束 | 补系数上下界、等式约束及核有效性条件 |
| 03 AHP | 小阶矩阵公式除零，经验阈值易被当统一标准 | 说明 n=1,2 的直接一致性与 RI 查表条件，区分经验判断和权重合理性 |
| 03 熵权 | 极值沿指标维计算，与后面的方案/指标定义冲突 | 按每个指标在方案维计算极值，统一索引 |
| 03 熵权 | 默认加常数消除零对数，忽略其对权重的影响 | 使用 0 ln 0 的极限约定，说明常数列、零效用和单方案的退化情况 |
| 03 TOPSIS | 贴近度及标准化可能除零 | 说明全零列与理想解重合时的处理需要 |
| 04 欧拉路径 | 只列度数奇偶，漏连通性与图类型 | 限定无向图，补非零度顶点连通条件，区分闭合与非闭合路径 |
| 04 哈密顿路径与匹配 | 将 NP 完全说成已证明无多项式算法，混用稳定与最大权匹配 | 改为目前没有已知一般多项式算法，明确稳定匹配需专门模型 |
| 05 预处理 | 仅按缺失比例删数据，异常阈值直接定性，插值与变换缺条件 | 补缺失机制、候选异常、等间距和预测时点、正值及零分母说明 |
| 05 Yeo-Johnson | 负值且 lambda 不等于 2 的分支漏负号 | 修正符号 |
| 05 DBSCAN、t 检验、Spearman、PCA | 暂定噪声不可改归类的歧义；公式名称或适用条件不全 | 说明边界点归类、Welch t、无并列秩简式、PCA 中心化及尺度选择 |
| 05 CCA | 把整体检验修正直接推广为含 k 的逐步公式 | 保留有条件的整体 Bartlett 近似，逐步检验另选适当方法 |
| 06 Monte Carlo | CLT 与区间缺少条件，未区分均值和积分尺度 | 补独立同分布、矩条件、大样本近似及积分缩放 |
| 06 马尔科夫链 | 混淆平稳分布存在和状态分布收敛，遗漏状态空间条件 | 说明有限状态不可约链的平稳分布与额外非周期性的不同作用 |
| 07 机器学习 | 一概承诺秒级耗时、离散化更好，分类固定 0.5，无条件要求标准化 | 改为条件性成本判断，说明离散化代价、阈值用途及按距离含义处理尺度 |

## 使用模型库时的判断

模型库的应用举例和参数经验不替代对本题的分析。尤其注意数据结构、样本量、模型假设、算法数值条件以及结果如何检验；这些判断可由模型主动完成并向人解释，不需要增加一套审批。

候选文献沿用原表，没有逐条联网核验。需要引用时核对书目信息，并阅读实际支持所用公式或主张的部分。部分算法介绍仍是简略说明，不应直接当作完整可执行模型；可继续查资料或自主推导。
