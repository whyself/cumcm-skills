# 模型选型与资料索引

本目录内包含模型选型建议和七类公式资料，可按问题需要直接读取。下面是辅助判断的参考，不是自动派发算法的决策树。

## 先判断问题结构

结合数据生成机制、数学结构、可解释性、可验证性和计算效率选方法。以下问题有助于判断：

1. 输出是解释关系、预测数值、判别类别、评价排序，还是做决策？
2. 数据是横截面、时间序列、重复测量、面板、空间数据还是组合决策数据？
3. 误差结构是连续、计数、二分类、比例、删失、偏态还是重尾？
4. 最终结论对误差有多敏感？

这些问题可以由模型根据材料直接分析，也可以帮助人澄清目标，不要求逐项问答。

## 按任务比较路线

| 任务 | 已有方法库中的基础候选 | 扩展方向 | 选取时关注 |
|---|---|---|---|
| 预测与参数估计 | 线性/岭回归、最小二乘、移动平均、指数平滑、ARIMA | GAM、状态空间、树模型、SVR、神经网络 | 数据生成机制、样本量、残差、时序验证；反演与未来预测不混为一谈 |
| 分类与识别 | 逻辑回归、朴素贝叶斯、KNN、决策树 | 随机森林、SVM、提升树、代价敏感学习 | 标签、可用特征、类别不平衡、阈值与错误代价 |
| 综合评价 | 明确权重的评分、原指标比较 | AHP、熵权、CRITIC、TOPSIS、VIKOR、DEA等 | 指标是否重复、权重是否有意义、排名是否稳定；能直接建模真实目标时不另造评分 |
| 优化与调度 | 枚举、LP/IP、动态规划、图算法 | 多目标、情景/鲁棒模型、启发式 | 先有数学目标和约束，再选求解算法；小规模可枚举时无需为复杂而复杂 |
| 聚类与结构发现 | K-means、层次聚类、PCA | GMM、DBSCAN、因子模型、非线性降维 | 距离和尺度、噪声、形状、稳定性及实际解释，聚类不能替代有标签分类 |
| 机理与系统 | 几何关系、守恒、差分/微分方程、概率递推 | 参数校准、现实修正、仿真、机理与数据结合 | 参数来源、近似条件、初边值、可辨识性和观测支持 |
| 网络与传播 | 最短路、流、匹配、网络指标 | 图优化、传播和韧性分析 | 节点、边、方向和权重怎样从题目得到 |
| 风险与不确定性 | 情景分析、Bootstrap、Monte Carlo | 随机规划、鲁棒优化、CVaR、贝叶斯分析 | 随机或区间依据、风险用途、保守代价及误差向决策的传递 |

基础与扩展是候选关系，不保证扩展更好。是否需要对比、集成或更复杂模型由问题和证据决定。表中部分方法仅在选型资料中提及，没有单独的公式条目；可以发挥自身知识并按需查找其他可靠资料。

## 常见组合的取舍

以下组合可用于不同问题，是否组合取决于实际需要：

- **规划与敏感性**：回答方案是什么以及受参数变化怎样影响。LP 对偶价格的解释依赖适用条件，不能直接套到所有整数规划。
- **启发式与对照**：用小规模精确解、已知界或可比较结果判断解的质量。对比好不等于证明全局最优。
- **多目标与折衷**：展示目标冲突和候选折衷，权重或选取依据服务人的实际偏好，不默认用 TOPSIS 替人决定。
- **单一预测与误差检验 / 多模型对比**：先看基线表现，差异和增益有证据时再考虑集成，不能预写“集成更准”。
- **赋权与评价 / DEA 效率分析**：先明确评价用途、指标含义和可比性，再看评分、排序或改进方向。
- **预测与决策**：例如需求预测进入库存优化，考虑预测误差是否改变决策。
- **机理与数据修正 / 图论与优化**：保留机理或网络的解释结构，说明后续算法具体补什么。
- **优化与模拟**：围绕同一个可执行决策考察不同情景。每个情景事后分别取最优，只能作理想信息基准等分析，不能据此称事前方案稳健。

模型可以建议组合，也可以判断无需组合。模型数量与调用顺序不由本表规定。
