# 验证参考

以下方法用于帮助判断模型和结果。按当前问题提出建议，与人按需要安排，不要求逐项执行或达到统一数量与阈值。

## 验证组合

可考虑的对照包括：手算小例与程序、解析结果与 Monte Carlo、主算法与另一计算方法、模型预测与实际数据、基础模型与修正模型。选择能针对当前疑点提供证据的组合，不为“独立验证”形式再堆一个模型。

| 问题结构 | 可考虑的检验 |
|---|---|
| 机理、几何、微分方程 | 单位、守恒、边界、极限、可解析特例、步长或网格变化 |
| 参数估计 | 残差、参数意义、多初值、区间、可辨识性与近似条件 |
| 预测、分类 | 留出或滚动回测、简单基线、匹配任务的误差或分类指标、外推风险 |
| 优化、调度 | 原始约束可行性、小实例枚举、解的界、求解耗时、初值与随机性 |
| 评价、聚类 | 权重与指标口径、排名或分组稳定性、结果的实际解释 |
| 仿真、不确定性 | 已知特例、分布依据、随机种子、模拟误差、情景一致性 |

误差口径结合用途选择：MAPE 对零值或接近零的值可能失真；平均误差不足以回答最坏情况问题。优化器返回可行解、局部最优和证明最优是不同结论，按实际证据说明。

## 数据和统计判断

先看缺失机制、异常原因、重复记录含义和时间泄漏；预测使用的信息应在预测当时可获得，拟合预处理和调参应尊重验证边界。

统计推断关注独立分析单位、重复测量和层级结构。多次测量或模拟运行不能直接当作新增独立观测；报告效应大小、不确定性和分析口径比只报显著性更有帮助。

相关关系不直接支持因果解释。未检出显著差异不证明相同；误差棒重叠不能直接判断差异是否显著；参数置信区间和未来观测预测区间应分别解释。

## 敏感性与现实修正

不机械对所有参数做上下浮动 5%，优先考察真正会改变方案的阈值、稳定区间和误差传播。扰动范围结合数据精度、参数来源或明确的探索情景，关联参数按合理组合变化。

基础模型出现系统偏差、题目加入现实条件、量级显示某效应不可忽略，或目标约束变化时，可以考虑修订。说明修订解决了什么问题，再用适当证据比较，不默认复杂模型更好。

## 如何看待反馈

先定位是数据映射、单位、数学关系、算法还是数值状态的问题，再建议修复。NaN/inf、病态性、变量尺度、收敛、初值和预算检查可按症状使用；不要求所有模型归一化或换用伪逆。

修改后更新受影响的判断与结果，避免引用失效证据。已有输入、参数、脚本和输出记录可支持追溯，但不要求固定文件或记录系统。

验证计划不等于验证结果，程序正常退出不等于模型正确，人的同意也不替代事实证据。实际没运行就说明没运行；作者自检不描述为独立验收。
